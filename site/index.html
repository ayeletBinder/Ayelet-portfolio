Test automation, applied to this site

I like to show quality work, not just describe it. This website is covered by a Playwright end-to-end suite that runs on every push in GitHub Actions. It checks navigation, the CV download, contact links, accessibility basics and a mobile layout with no horizontal scrolling.

The tests live in the tests/ folder of this site's repository.

test('CV can be downloaded', async ({ page }) => {
  await page.goto('/');
  const [download] = await Promise.all([
    page.waitForEvent('download'),
    page.getByRole('link', { name: /download cv/i }).click(),
  ]);
  expect(download.suggestedFilename())
    .toMatch(/\.pdf$/);
});
